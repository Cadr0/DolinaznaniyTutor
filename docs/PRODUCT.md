# Продукт

## Назначение

Платформа **«Долина знаний»** для репетиторов и учеников.

## Роли

| Роль | Возможности |
| ---- | ----------- |
| **Репетитор** | Комнаты, материалы, маркетплейс, карточка ученика, проверка фото, назначение ДЗ |
| **Ученик** | Комнаты, домашняя работа, интерактивный плеер, прогресс |
| **Админ** | (позже) модерация |

## Сущности (актуальная модель)

```
User
  └── TaskTopic + Task          ← банк репетитора (/dashboard/materials)
        │ isPublished
        ▼
      Marketplace
        │ copyTopicToRoom / copyBankTopicToRoom
        ▼
      Room (комната)
        └── RoomTopic + RoomTask   ← снимок в комнате
              │ assignTopicToStudent
              ▼
            StudentTopicAssignment
              └── StudentTaskProgress + StudentTaskAttempt
```

Подробнее: [SYSTEM.md](SYSTEM.md).

## Маркетплейс

- Репетитор публикует темы в каталог (`TaskTopic.isPublished`)
- Любой репетитор копирует тему в свою комнату
- Свои темы можно копировать в комнату **напрямую из материалов** без публикации
