# Продукт

## Назначение

Платформа **«Долина знаний»** для репетиторов и учеников.

## Роли


| Роль          | Возможности                                                         |
| ------------- | ------------------------------------------------------------------- |
| **Репетитор** | Регистрация, комнаты, приглашение учеников, задания, проверка работ |
| **Ученик**    | Личный кабинет, выполнение заданий в комнатах                       |
| **Админ**     | (позже) модерация маркетплейса                                      |


## Сущности

```
User
  └── Room (комната репетитора)
        ├── RoomMember (ученики)
        └── Assignment (задание)
              └── Submission (ответ ученика)

MarketplaceTask (каталог)
  └── копируется в Assignment
```

Схема в коде: `prisma/schema.prisma`.

## Маркетплейс

- Репетитор публикует задания в общий каталог
- Другие репетиторы берут задания в свои комнаты
- Свои материалы + чужие из маркетплейса
