# Сводка улучшений — 2026-05-24

## Что сделано

### 1. Карточка ученика (главный запрос)

| Функция | Где |
| ------- | --- |
| Полная карточка с логами попыток | `/dashboard/students/[studentId]` |
| Быстрый просмотр в модалке | Комната → «Прогресс →» (расширенная панель) |
| Список всех учеников с метриками | `/dashboard/students` |
| Ссылка из drawer «Ученики» | `/dashboard/rooms` → кнопка «Ученики» |

**В карточке ученика:**
- статистика: выполнено / с ошибками / подсказки / тем назначено;
- переключение комнат (если ученик в нескольких);
- список назначенных тем с датой назначения;
- раскрытие каждой задачи → **все попытки** (текст, варианты, фото, верно/неверно, время, подсказка);
- показ **верного ответа** для контекста;
- **назначить тему** и **снять назначение**;
- ссылка «Полная карточка» из модалки в комнате.

### 2. Проверка фото-ответов

- `/dashboard/review` — очередь IMAGE-ответов со статусом SUBMITTED
- Просмотр фото, комментарий, **Принять** / **Отклонить**
- Ссылка на карточку ученика

## Как проверить на prod

1. **Учитель** → `/dashboard/students` → открыть карточку → раскрыть задачу → увидеть попытки
2. **Учитель** → Комната → ученик → «Прогресс →» → модалка + «Полная карточка»
3. **Учитель** → `/dashboard/review` — если есть SUBMITTED фото
4. **Учитель** → Материалы → тема с заданиями → «В комнату»
5. **Главная** `/dashboard` — счётчики комнат, учеников, проверки

```bash
E2E_BASE_URL=https://diary-ai.ru npm run test:e2e
```
